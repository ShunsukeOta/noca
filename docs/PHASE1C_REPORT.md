# Phase 1C — カレンダー CRUD 実装・検証記録

更新: 2026-10-14

## 実装範囲

- 予定の新規追加・編集・削除・Undo（約6.5秒間）
- 選択した日付を右下の「＋」と追加用シートへ引き継ぐ
- タイトル必須、日付必須、終日/時刻指定、開始時間・終了時間（任意）
- 終了時間が開始時間以下の場合は保存を拒否（同一日の予定のみ）
- カテゴリ・場所・メモは折りたたみ式の任意入力
- 予定のある日のカレンダーにドットを描画。期限付きTODOは別色で表示
- 選択日の予定を終日→開始時間順で並べて表示。期限TODOは同じアジェンダに参照表示
- 予定一覧タップで予定シート、期限TODOタップで既存TODO編集シート
- iPhone幅の月移動、日付選択、リスト表示のアニメーション。reduced-motion対応
- **端末localStorage仮保存**。予定とTODOは別データで重複保存しない

## 保存仕様

- Local key: `noca.calendar.events.v1`
- 初回のみダミー予定を表示。配列 `[]` 保存後にサンプルを復活させない
- 同じブラウザの再読み込み後も予定は保持される
- 保存失敗時は画面に警告を表示
- ユーザー自身でブラウザデータを消すと予定も消える。**2人共有やFirebase同期は未実装**
- `date`: `yyyy-MM-dd`、`time/endTime`: `HH:mm`。日時は端末のローカル日付・時刻として解釈する
- 日をまたぐ予定・繰り返し予定・外部カレンダー連携は今回未対応
- 実機Safari/PWAで日付・時間入力の使いやすさを最終確認（Phase 1E）
