# Phase 1B — TODO CRUD UI実装記録

更新: 2026-10-14

## 機能と設計

目的: iPhone向けの既存デザインを維持したまま、TODOをタスク管理として操作できる状態にする。Firebaseの認証・複数人共有はまだ実装しない。

### 画面操作

- 右下「＋」→ タイトルを入力して追加（カテゴリ・期限は任意）
- 一覧のチェック → 完了／解除
- タスク本文タップ → 下部シートで編集
- 期限: iPhone標準の日付入力。解除も可能
- カテゴリ: 「その他」「暮らし」「おでかけ」「ふたり」
- 詳細を追加: メモ／URL／場所を折りたたみ表示
- 編集シート → 削除 → 約6.5秒間Undoボタンを表示
- 完了タスク一覧は折りたたみ表示
- 「すべて」「今日」「今週」で絞り込み
- 期限付きの未完了TODOをカレンダーにも表示。双方から同じTODOを編集

### 保存と制限

- **localStorageの`noca.todos.v1`に端末ローカル保存**。同じPWA/ブラウザのリロードで残る。
- **Firebase・アカウント・2人同期はまだ接続していない。** Safariとホーム画面PWAで保存領域が共有される保証もない。
- 初回はサンプルTODOを投入する。全削除後も自動でサンプルを復活させない。
- ブラウザデータを削除した場合、TODOも消える。Phase 2–3でFirebase永続保存に置き換える。
- localStorage書き込みに失敗した場合は保存できない旨を表示する。
- プレビュー環境のデータは本番データとして扱わない（移行・バックアップは未実装）。

## テスト

- GitHub Actions / PlaywrightにTODO新規追加→再読み込み→編集→削除→Undoのテストを追加。
- 期限付きTODOをカレンダーで確認し、完了すると非表示になるケースを追加。
- 375/390/430pxの横スクロール確認は従来どおり実行。
- iPhone実機 Safari / ホーム画面 PWA は Phase 1E で確認。
